# 🔍 Сахарный детектив: PRO Edition (Hidden Sugar Detective)

> **Образовательная интерактивная детективная веб-игра по разоблачению скрытого сахара в повседневных продуктах питания.**  
> Создана в строгом соответствии с EdTech-стандартами верстки, визуализации и интерактивного обучения школьников и подростков (10–11 класс).

---

## 🎯 Миссия и образовательная цель

В современных переработанных продуктах содержится колоссальное количество скрытого добавленного сахара под десятками псевдонимов (мальтодекстрин, патока, декстроза, сироп агавы, изомальтоолигосахарид и др.). Подростки ежедневно употребляют 100–150 г сахара (20–30 чайных ложек), превышая норму ВОЗ (25 г / 5–6 ложек) в 4–6 раз.

**Цель игры:** сформировать у учеников устойчивый навык осознанного чтения этикеток, распознавания маркетинговых уловок («0% жира», «Фитнес», «Натуральный продукт») и перевода абстрактных углеводов в наглядные чайные ложки сахара.

10. **Уровень 10: Паназиатская кухня и Стрит-фуд (6 вопросов)** — Рис для суши (мирин и рисовый уксус), молочный бабл-ти с тапиокой (14 ложек!), соус хойсин, вок в кисло-сладком соусе, соевый соус без сахара, сладкий чили (порция 50 г).

13. **Уровень 13: Аптека и БАДы (5 вопросов)** — Леденцы от кашля, сироп от температуры, жевательные витамины-мишки, шипучий витамин C, гематоген.

## 🛒 Экономика и Магазин Детектива

Игрок зарабатывает детективные монеты за каждый правильный ответ (с анти-фарминг защитой от повторного начисления за пройденные вопросы). Стартовый капитал: **100 монет**.

### Расходные бустеры:
1. **🔍 50:50 (30 монет)** — удаляет 2 заведомо неверных варианта ответа.
2. **🛡️ Сахарный щит (35 монет)** — пассивно поглощает следующую ошибку, защищая жизнь детектива (3/3 HP).
3. **💡 Подсказка эксперта (20 монет)** — раскрывает научную подсказку и подсвечивает ключевое слово в составе.
4. **❤️ Аптечка первой помощи (40 монет)** — мгновенно восстанавливает 1 потерянную жизнь.
5. **❄️ Заморозка времени (25 монет)** — останавливает таймер на 15 секунд в Блиц-Марафоне.

### Кастомизация:
- **8 Аватаров детектива:** Стажер, Шерлок, Кибер-Сыщик, Биохимик, Мастер-Шеф, Робот-Аналитик, Профессор Нутрициологии, Гроссмейстер.
- **5 Тем оформления UI:** Неоновый Нуар (по умолчанию), Изумрудная Лаборатория, Киберпанк Индиго, Теплый Янтарь, Высококонтрастная (для доступности).
- **3 Секретных досье:** «Анатомия 56 псевдонимов сахара», «Сахарная ловушка обезжиренных продуктов», «Маркетинговые уловки на детских этикетках».

## 🛠️ Архитектура и технологии

Проект написан на **чистом ванильном JavaScript (ES5/ES6)** без тяжелых фреймворков и сторонних npm-зависимостей:
- `index.html` — семантическая разметка с карточной сеткой и модальными окнами.
- `css/style.css` — модульная дизайн-система на CSS Custom Properties с поддержкой тем.
- `js/data.js` — полная база данных (15 уровней, 81 вопрос, магазин, ачивки).
- `js/state.js` — изолированное состояние (localStorage, схема v2, события подписчиков).
- `js/graphics.js` — процедурный SVG-рендерер (69 продуктов, 28 иконок, 3D кубики, диплом).
- `js/audio.js` — процедурный синтезатор на Web Audio API (16 SFX + 8-bit саундтрек).
- `js/confetti.js` — 2D Canvas движок праздничного конфетти.
- `js/app.js` — контроллер пользовательского интерфейса и игровых механик.

## 👨‍🏫 Инструкция для преподавателя

1. Откройте файл `enhanced_game/index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).
2. Подключение к интернету не требуется — игра работает на 100% автономно в оффлайн-режиме.
3. Доступна панель учителя для быстрого тестирования: в консоли разработчика введите `SugarApp.State.unlockAllLevels()` или нажмите секретную комбинацию в футере для доступа к панели отладки.
